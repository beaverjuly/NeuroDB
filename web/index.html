Database overview

NeuroDB integrates behavioral observations, experimental event timing and computational model outputs into a relational MySQL database. Explore the data through predefined queries, execute custom SQL and compare alternative physical database designs.

How records reach NeuroDB

OSF behavior and timing→Identity and checksum checks→Event alignment→MySQL tables→Live queries
Behavioral and event timing data cover 189 participants. Computational model outputs are available for one validated pilot participant.

Data & Provenance
Data sources
Behavior CSV and timing MAT files came from OSF project CTFZD. Participant identity was checked against OpenNeuro ds007474 version 1.0.5. The loader records file versions, checksums, transformation status and run mappings.
OSF project ↗ · OpenNeuro version ↗
Data coverage
189 participants passed the implemented source and event alignment checks. This does not identify which participants were in the paper's 179-person analytic sample. One previously validated pilot provides model parameters and latent values.
Missed-response trials terminate early and therefore contain fewer events than completed trials. The database preserves these legitimate missing observations without imputing unobserved events.
